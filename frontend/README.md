# Legal Assistant & Generative AI Detection - Frontend

A modern React + Vite frontend for the RAG-based Legal Assistant Chatbot.

## Key Features
- **Interactive Chat Interface**: Dynamic message streams with user and AI dialogue history.
- **Dynamic Retrieval Complexity Badges**: Real-time visualization for query tiers (`simple`, `complex`, `multi-hop`).
- **Source Document Transparency**: Citations showing retrieved legal chunks and similarity scores.
- **Preconfigured Legal Prompts**: Fast access to contract review, compliance, and liability checks.
- **Configurable Settings**: Custom API endpoints, model parameters, and retrieval depth (`top_k`).

## Setup and Running

```bash
# 1. Navigate to frontend directory
cd frontend

# 2. Install dependencies
npm install

# 3. Start development server
npm run dev
```

The application runs on `http://localhost:5173`.
